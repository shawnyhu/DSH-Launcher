# Support

Use GitHub Issues for reproducible Launcher bugs and feature requests.

Include the following information:

- Operating system and version
- CPU architecture (`x64` or `arm64`)
- Launcher version and Release tag
- DSH version
- Node.js version and installation source
- DSH installation scope (global or Launcher-managed)

For DeepSeek Harness behavior that also occurs when running `dsh` directly, report it to the upstream DeepSeek Harness project.

Never attach API keys, `.credentials.yaml`, private DSH_HOME contents, conversation data, signing credentials, or update private keys.

# macOS Changelog

## 0.2.0 - 2026-08-21

- 新增原生 SwiftUI/AppKit 菜单栏应用与 macOS 配置窗口。
- 新增 Node.js 兼容性发现、npm 全局/托管安装和多 DSH 版本管理。
- 新增 `DSH_HOME` 管理、写入版本观察和凭据文件排除规则。
- 新增 DSH 进程所有权保护、就绪检测、启动/停止/重启和 Web UI 打开流程。
- 新增会话、任务、提问、审批事件监控和 macOS 通知。
- 新增登录项管理，以及仅接受 `mac-v*` 的签名更新通道。
- 新增原子设置存储、损坏配置隔离、日志、核心自检和 macOS CI。
- 新增 Apple Silicon `.app`、完整 `.pkg`、轻量更新 `.pkg`、校验和及签名更新清单构建。
- macOS 源码、用户数据、缓存、日志、构建产物和发布标签与 Windows 版本保持隔离。
- 修复配置列表挤出操作栏的问题；补齐 DSH 版本安装、单独更新、重装、卸载，以及 `DSH_HOME` 新增、编辑、显示和移除操作；版本和 `DSH_HOME` 列表均持续标明当前使用项，不受临时行选择影响。
